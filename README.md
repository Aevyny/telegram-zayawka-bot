# 📩 Telegram Application Bot

Telegram-бот для автоматизированного сбора заявок от пользователей с помощью пошаговой анкеты. После заполнения данные сохраняются в SQLite и отправляются администратору.

Проект разработан на Python с использованием aiogram 3.x.

## ✨ Возможности

### 👤 Для пользователей
- Запуск бота через `/start`.
- Пошаговое заполнение анкеты:
  - Имя.
  - Номер телефона.
  - Комментарий или описание запроса.
- Просмотр и подтверждение заявки перед отправкой.
- Возможность заполнить анкету заново или отменить её.
- Уведомление об успешной отправке заявки.
- Ограничение частоты отправки заявок.

### 🛠 Для администратора
- Получение новых заявок в личные сообщения.
- Просмотр информации о заявителе:
  - Имя.
  - Номер телефона.
  - Комментарий.
  - Telegram Username.
  - Telegram ID.
- Возможность ответить пользователю прямо через бота.
- Просмотр последних 10 заявок через команду `/requests`.

## ⚙️ Технологии

- **Python 3** — основной язык разработки.
- **aiogram 3.x** — взаимодействие с Telegram Bot API.
- **SQLite** — хранение заявок.
- **aiosqlite** — асинхронная работа с базой данных.
- **FSM** — управление состояниями диалога.
- **python-dotenv** — загрузка конфигурации из `.env`.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/telegram-application-bot.git
```

```bash
cd telegram-application-bot
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```bash
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта на основе `.env.example`.

Укажите следующие параметры:

```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=123456789

COOLDOWN_SECONDS=600

DB_PATH=data/requests.db
```

- `BOT_TOKEN` — токен Telegram-бота.
- `ADMIN_ID` — Telegram ID администратора.
- `COOLDOWN_SECONDS` — интервал между отправками заявок в секундах.
- `DB_PATH` — путь к базе данных SQLite.

### 5. Запуск бота

```bash
python main.py
```

При первом запуске база данных и необходимые таблицы создаются автоматически.

**Важно:** администратору необходимо предварительно запустить бота командой `/start`, чтобы бот мог отправлять ему уведомления.

## 🗄 База данных

Для хранения заявок используется SQLite.

Основная таблица `requests` содержит:

| Поле | Описание |
|---|---|
| id | Уникальный идентификатор заявки |
| user_id | Telegram ID пользователя |
| username | Telegram Username |
| name | Имя заявителя |
| phone | Номер телефона |
| comment | Комментарий |
| created_at | Дата и время создания |
| status | Статус заявки |

## 🔒 Безопасность

- Токен бота и ID администратора хранятся в `.env`.
- Файл `.env` исключён из Git.
- База данных с пользовательскими данными не публикуется в репозитории.
- Доступ к административным командам ограничен по Telegram ID.
- Реализовано ограничение частоты отправки заявок.
